C O M M O N S

One desk,
one vocabulary.

smearor-commons is a mono-workspace of shared, framework-agnostic Rust libraries for the Smearor ecosystem — frameworks, applications and games for the 65 ″ table-top smart desk. Pure std cores, optional integrations behind feature gates, published to crates.io.

Design

Built to be embedded.

The crates provide technical, domain-free vocabulary — semantic newtypes like FigureColor or BoardOrientation live in the consuming crates as thin wrappers around these types.

Pure std core

The default feature set pulls no GUI, compositor or schema framework dependencies — every crate stays usable in headless consumers.

Feature-gated integrations

Transport, schema and UI conversions live behind optional features named after their dependency: async-graphql, schemars, zbus, evdev, gtk4, cairo, smithay.

Strict newtypes

Domain primitives are wrapped in newtype structs and every crate has its own thiserror error enum — panic-free by convention.

serde by default

Serialization support is a base dependency, not a feature — every technical type round-trips out of the box.

Mono-workspace

All crates live under crates/*, share workspace.package metadata and release with a common version.

Get started

Add it to your Cargo.toml.

Pick only the crates you need — integrations stay off until you ask for them.

Cargo.toml 
[dependencies]
smearor-commons-geometry = "0.1"
smearor-commons-layout   = "0.1"
# optional integrations, e.g. GTK4:
smearor-commons-buffer   = { version = "0.1", features = ["gtk4"] }
