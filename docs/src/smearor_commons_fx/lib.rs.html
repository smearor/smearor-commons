1//! # smearor-commons-fx
2//!
3//! Headless, serializable per-pixel effects over frozen textures -
4//! the Rust analogue of Burn-My-Windows' shader effects, generalized
5//! to any rectangular content (widgets, cards, sprites) a consumer
6//! can snapshot into a [`PixelBuffer`](smearor_commons_buffer::PixelBuffer).
7//!
8//! ## Architecture
9//!
10//! - [`FxContext`] is the uniform block an effect sees for one frame
11//!   (progress, direction, seed, textures) - the crate is clock-free;
12//!   consumers drive it with `TimedAnimation`.
13//! - [`WindowEffect`] is the effect abstraction: identity, parameter
14//!   metadata, frame application.
15//! - [`ParamSpec`]/[`ParamKind`]/[`ParamValue`] are the metadata model
16//!   that generates GTK controls, serde defaults and codegen.
17//! - [`EffectSpec`] is the serde-tagged dispatch root - one variant
18//!   per shipped effect, serializing as `{"effect": "crossfade", ...}`.
19//!
20//! The default feature set is pure-std headless; `gtk4`, `cairo`,
21//! `schemars` integrations live behind dependency-named features.
