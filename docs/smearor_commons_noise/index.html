§smearor-commons-noise

Deterministic procedural noise: the Hoskins hash family as a generic Hash trait, table-free simplex fields (Simplex2D, Simplex3D) and a generic fractal-Brownian-motion combinator (Fbm) - all over [Vec2]/[Vec3]/[Vec4] from smearor-commons-geometry.

§Determinism

The hash family is sine-free (fract, multiply, add only - David Hoskins’ “hash without sine” recipe), so it is bitwise stable across platforms and math libraries. Both simplex fields build their gradients from hash22/hash33 (the Burn-My-Windows/MIT-licensed variants), which keeps the whole crate deterministic: a given Seed always replays the same field.

Structs§

Fbm
Generic fractal Brownian motion over any base Field: sums octaves scaled-and-faded copies of the field, lacunarity scaling frequency and gain scaling amplitude per octave.
Gain
Amplitude multiplier per crate::Fbm octave - the classic fBm gain is 0.5 (each octave halves in amplitude).
Lacunarity
Frequency multiplier per crate::Fbm octave - the classic fBm lacunarity is 2.0 (each octave doubles in frequency).
Octaves
Octave count of an crate::Fbm - 1..=8 is the sensible range; the wrapper prevents accidentally feeding a Gain where an octave count belongs.
Seed
Deterministic per-run seed - wraps the raw u64 so call sites cannot accidentally feed an arbitrary offset where the run’s seed belongs. Serializes as a plain number.
Simplex2D
2D hash-simplex field - output in [0, 1] (0.5 + 0.5 * dot(n, 70.0) semantics).
Simplex2DFractal
The fixed four-octave fractal variant of Simplex2D - rotates and scales the domain by mat2(1.6, 1.2, -1.2, 1.6) between octaves to break up directional artifacts, weights 0.5/0.25/0.125/0.0625.
Simplex3D
3D hash-simplex field - output in [0, 1] (dot(d, 52.0) * 0.5 + 0.5 semantics, the Burn-My-Windows renormalized variant).
Simplex3DFractal
The fixed four-octave fractal variant of Simplex3D - rotates the domain by three fixed mat3 matrices between octaves to break up directional artifacts, weights 0.5333/0.2667/0.1333/0.0667.
