Expand description

The Hoskins fract-hash family.

p.hash() returns the Out-shaped hash of p with every component in [0, 1). The 13 impls mirror the GLSL hashNN naming (input dimension + output dimension); each impl’s rustdoc names its hashNN designation. This is not std::hash::Hash - the no-arg Out-returning signature never collides at call sites.
