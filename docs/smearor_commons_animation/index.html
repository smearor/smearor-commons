Timed animations for the Smearor ecosystem.

Pure std core: an TimedAnimation pairs a Trajectory - the shape of the animated output - with a [Duration] and an EasingFunction. Trajectories compose: Span interpolates between two values of any Interpolate type, ThreePhaseSpan eases out, holds and eases back, and (S1, S2) tuples animate composite values on one clock. The gtk4 feature gate adds the frame-clock driver that pumps an animation on a widget.

serde is unconditional; schemars schema derives live behind their feature gate.
