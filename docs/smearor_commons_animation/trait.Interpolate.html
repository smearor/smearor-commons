Expand description

A value that can be interpolated between two endpoints along a normalized progress t (0 = self, 1 = target).

t is not clamped - easing curves like crate::EasingFunction::Overshoot deliberately extrapolate, and each type decides what extrapolation means: plain scalars just keep going, RotationRad keeps turning past the target on the shortest arc and settles back.
