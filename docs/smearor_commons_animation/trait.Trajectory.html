Expand description

Maps eased progress t (conventionally 0.0..=1.0, easing may exceed it) to an animated value - the shape of an animation’s output over time.

Implementations: crate::Span for a two-endpoint interpolation, crate::ThreePhaseSpan for an ease-out / hold / ease-in pattern, and (S1, S2) tuples for composite values animated on one clock.
