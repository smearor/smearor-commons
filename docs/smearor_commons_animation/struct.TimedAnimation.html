Expand description

An eased, timed animation over any Trajectory: pairs the trajectory with a Duration and an EasingFunction and produces eased values once Self::started.

TimedAnimation<Span<RotationRad>> is the shortest-arc rotation animation; TimedAnimation<Span<ScaleFactor>> the zoom animation; TimedAnimation<(Span<RotationRad>, ThreePhaseSpan<ScaleFactor>)> a rotation-zoom composite - one clock, two trajectories.

The clock state (start_time) is runtime-only and skipped in serialization - a deserialized animation is unstarted.

Fields§

§trajectory: S

The value trajectory - the shape of the animated output.

§duration: Duration

How long the animation runs after Self::start.

§easing_function: EasingFunction

The progress curve applied to linear time.
