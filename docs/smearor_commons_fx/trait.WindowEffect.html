Expand description

A per-pixel effect over frozen textures - the analogue of one Burn-My-Windows shader.

Implementors are plain serde structs (the EffectSpec variant payloads); the trait adds identity, parameter metadata and the frame application.

fn apply(&self, ctx: &FxContext<'_>, out: &mut BufferViewMut<'_, Rgba>)

Render one frame: read ctx, write out fully (every pixel).

fn layers(&self) -> Layers

The layers this effect renders - Layers::SurfaceAndWindow makes the consumer run two passes and supply ctx.surface.

Source

fn check(&self, ctx: &FxContext<'_>) -> Result<(), FxError>

Pre-flight check for a pass: Err(MissingSurface) when this is a two-pass effect and ctx.surface is None.
