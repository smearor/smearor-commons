Expand description

The window splits into a grid of panels (the Portal wall panels) that flip over one after another - each panel’s front shows what was behind the window, its back the window.

Behavioral spec (source shader: aperture-panels.frag, re-implemented from semantics): the visible window (uFrame = ctx.window_rect) is cut into a cols × rows grid, uCell dividing it exactly (aperture-panels-panel-size is the target, snapped so it fits). cellTiming squeezes every flip into [border_lead, 1 - border_trail] of the timeline, staggered by wavePosition (five wave_shapes, 5 = random picked from the seed) - each panel turns local * PI around its centre axis (flip_axis 0 = vertical squash axis per FLIP_AXIS_VERTICAL, 2 = random), projected with PERSPECTIVE and inverted to panelUV. Front faces (local ≤ 0.5) show the surface texture, back faces the window; gaps stay transparent or take the backdrop (black void / star field / nebula; Transparent also skips painting the surface on front faces - the real backdrop shows through). The EDGE_SHADE darkens turning panels, the border_style runs an outline wave ahead of and/or behind the flip wave (BORDER_LEAD/BORDER_TRAIL). In the shadow margin (outside uFrame) the surface pass copies the texture and the window pass fades the shadow in once the nearest edge panel turned. easter_egg enables the cake at CAKE_CHANCE (the seed decides, uCakePos hashes it inside the window).

Two-pass effect: Layer::Surface paints the windows-behind faces and the backdrop, Layer::Window the window faces and the shadow margin - the consumer composites window over surface.

Wave shape 0..=5 (5 = random) - schema aperture-panels-wave-shape, default 4.

Flip axis 0 = around a vertical axis, 1 = horizontal, 2 = random - schema aperture-panels-flip-axis, default 0.

Border colour - schema aperture-panels-border-color, default rgba(0, 0, 0, 0.4).

§backdrop: Backdrop

What shows behind the panels - schema aperture-panels-backdrop, default wallpaper.

§easter_egg: bool

Cake easter egg - schema aperture-panels-easter-egg, default true.
