Expand description

Green rain glyphs fall down the window while it dissolves beneath them - the Matrix effect.

Behavioral spec (source shader: matrix.frag, re-implemented from semantics): the texture is vertically overscanned by overshoot (uv.y mapped to [-overshoot/2, 1+overshoot/2]). Per scale-px column a deterministic delay and speed place a “raindrop” whose exponential tail (TRAIL_LENGTH) fades the glyph mask; the window alpha follows the drop with a FADE_WIDTH-px gradient. Glyph coverage comes from a GlyphSource - the bundled ProceduralGlyphAtlas replaces BMW’s matrixFont.png bitmap. A FINAL_FADE_START_TIME tail-fade extinguishes the trails at the end.

Note on the column RNG: BMW’s rain-column hash is the sinus hash (fract(sin(column) * 78.233)), not the Hoskins family - kept as a private [column_hash] for deliberate parity.

Trail color - schema matrix-trail-color, default rgb(25, 255, 89).

§overshoot: Fraction

Vertical overscan 0..=1 - schema matrix-overshoot, default 0.25.
