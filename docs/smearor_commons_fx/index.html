§smearor-commons-fx

Headless, serializable per-pixel effects over frozen textures - the Rust analogue of Burn-My-Windows’ shader effects, generalized to any rectangular content (widgets, cards, sprites) a consumer can snapshot into a PixelBuffer.

§Architecture

  • FxContext is the uniform block an effect sees for one frame (progress, direction, seed, textures) - the crate is clock-free; consumers drive it with TimedAnimation.
  • WindowEffect is the effect abstraction: identity, parameter metadata, frame application.
  • ParamSpec/ParamKind/ParamValue are the metadata model that generates GTK controls, serde defaults and codegen.
  • EffectSpec is the serde-tagged dispatch root - one variant per shipped effect, serializing as {"effect": "crossfade", ...}.

The default feature set is pure-std headless; gtk4, cairo, schemars integrations live behind dependency-named features.
