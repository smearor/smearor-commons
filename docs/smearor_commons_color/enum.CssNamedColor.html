Expand description

A CSS <named-color> keyword from the W3C CSS Color Module Level 4 spec (the former “CSS3 color names”).

The enum covers all 148 keywords - including the Level 4 addition rebeccapurple and the gray/grey spelling variants - plus the transparent keyword. currentcolor is context-dependent and intentionally not represented.

Keywords parse ASCII case-insensitively via FromStr, like in CSS; Display and the wire format use the canonical lowercase keyword.
