Expand description

Defines the color vocabulary of a crate::Palette: which semantic color slots exist and how they are named.

Implemented by the palette’s key type - typically a fieldless enum in the consuming crate. With an enum key every lookup is type-checked: palette.get(&BoardSlot::Light) cannot address a name that does not exist, crate::Palette::missing reports slots without a color and crate::Palette::is_complete verifies that all declared slots are filled.

The crate::palette_definition! macro generates a fieldless enum plus this implementation from a compact name list.

Key types with a dynamic vocabulary (like crate::NamedColor) cannot implement PaletteDefinition - they stay usable as palette keys, just without the completeness checks.

All color slots of the palette in declaration order - the canonical list for completeness checks and ordered iteration.

The semantic name of this slot ("light", "ink", …) - used for display and diagnostics.
