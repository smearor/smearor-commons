Macro static_palette 

Source 
macro_rules! static_palette {
    ($($name:expr => $color:expr),* $(,)?) => { ... };
}
Expand description

Builds a StaticPalette from name => color pairs - the generated expression is const-evaluable and usable in const and static contexts. All values must be const expressions (Color::<u8>::new(0xED, 0xD4, 0x9E) or Color::<u8>::from_rgb_u32(0xEDD49E)) and names must already have the key type (BoardSlot::Light, NamedColor::new("light")) - no Into conversion happens in const contexts.

use smearor_commons_color::Color;
use smearor_commons_color::StaticPalette;
use smearor_commons_color::static_palette;

const GRAYSCALE: StaticPalette<&'static str, u8> = static_palette! {
    "light" => Color::<u8>::from_rgb_u32(0xEDD49E),
    "dark" => Color::<u8>::from_rgb_u32(0x734D2E),
};
assert_eq!(GRAYSCALE.len(), 2);
