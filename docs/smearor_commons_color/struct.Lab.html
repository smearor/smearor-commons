Struct Lab 

Source 
pub struct Lab {
    pub l: LabLightness,
    pub a: f64,
    pub b: f64,
}
Expand description

A CIE L*a*b* (CIELAB, 1976) color at the D65 white point.

l is the perceptual lightness (0 = black, 100 = diffuse white), a the green-to-red and b the blue-to-yellow opponent axis.

Fields§

§l: LabLightness

The perceptual lightness L* (conventionally 0.0 - 100.0, extrapolated values allowed).

§a: f64

The green (a < 0) to red (a > 0) opponent component.

§b: f64

The blue (b < 0) to yellow (b > 0) opponent component.
