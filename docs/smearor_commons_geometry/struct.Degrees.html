Struct Degrees 

Source 
pub struct Degrees(pub f64);
Expand description

An angle in degrees - the scalar unit for boundaries where angles are expressed in degrees (display strings, wire formats, f32 framework APIs like gsk transforms).

Unlike crate::RotationRad - the quantity type with angle semantics (wrapping, sin_cos, deltas) - Degrees is a plain scalar: it carries the unit but no rotation behavior. Serializes as a bare number.
