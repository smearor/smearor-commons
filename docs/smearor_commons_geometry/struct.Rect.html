Struct Rect 

Source 
pub struct Rect<U = (), T = f64> {
    pub min: Vec2<U, T>,
    pub size: Vec2<U, T>,
}
Expand description

An axis-aligned rectangle tagged with its coordinate unit U and numeric component type T.

min is the top-left corner, size the extent (size.x = width, size.y = height); right/bottom are the max edges. The phantom unit keeps millimeter regions and pixel footprints from mixing; T defaults to f64 for domain math while the unit-erased Rect<(), i32>/Rect<(), f32> forms (alias crate::Rectangle) serve integer and float boundaries - smithay Rectangle<i32, K> and graphene Rect alike.

pub fn rotated_region_scanlines(&self, rotation: RotationRad) -> Vec<Scanline>

Rasterizes this rectangle’s extent rotated by rotation around its center into horizontal scanline strips.

Returns Scanlines relative to the rectangle’s center (y-down screen coordinates); each strip is one pixel high. Callers add the actual center to map the strips onto cairo::RectangleInts or similar integer regions.

Source

pub fn rotated_region(&self, rotation: RotationRad) -> Result<Region, Error>

Rasterizes the rectangle rotated by rotation around its center into a cairo Region in the rectangle’s own coordinate space - one 1-px-high RectangleInt per rotated_region_scanlines strip, offset by the rect’s center.

Used e.g. to describe the input region of a rotated GTK widget on a wayland surface.

§Errors

Propagates [cairo::Error]s from Region construction.

Source

pub fn clamp_offset(&self, bounds: &Self, min_visible: U) -> Vec2<U>
where U: Into<f64>,

The minimal translation needed so that at least min_visible (a scalar in the unit U) of this rectangle overlaps bounds on each axis.

Applying the returned offset to the rectangle’s position moves it back inside the bounds. The overlap requirement is capped at half the bounds size so it stays satisfiable on very small bounds.

Source

pub fn contain_offset(&self, bounds: &Self) -> Vec2<U>

The minimal translation needed so that this rectangle lies entirely inside bounds.

On axes where the rectangle is larger than the bounds it is centered, so it stays reachable instead of snapping to one edge.
