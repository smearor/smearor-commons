Struct Vec3

pub struct Vec3<U = (), T = f64> {
    pub x: T,
    pub y: T,
    pub z: T,
    /* private fields */
}
Expand description

A 3D point or vector tagged with its coordinate unit U and numeric component type T.

The phantom unit distinguishes positions in millimeters (Vec3<Millimeters>), raw device units and screen pixels (Vec3<Pixels>) so they cannot be mixed up; T defaults to f64 for domain math. The unit-erased form Vec3<(), T> is the boundary representation - it deliberately carries no coordinate-space claim, mirroring crate::Vec2. Serializes as a flat {"x": .., "y": .., "z": ..} map; the unit marker is skipped.
