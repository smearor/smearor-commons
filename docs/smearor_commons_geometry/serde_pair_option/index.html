Module serde_pair_option 

Source
Expand description

Serde adapter for #[serde(with)]: Option<Vec2<U>> as a compact [x, y] pair - the absent-tolerant form of serde_pair. Serializes Some as [x, y] and None as null; combine with #[serde(default)] on the field so a missing key also yields None.
