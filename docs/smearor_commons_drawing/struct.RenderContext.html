Struct RenderContext 

Source 
pub struct RenderContext<'a, T: DrawTarget> { /* private fields */ }
Expand description

Builder context for rendering icons, text, and UI elements onto a DrawTarget.

The context owns its target — T is typically &mut PixelBuffer, BufferViewMut, or a backend target like CairoTarget (the capability traits and DrawTarget are implemented for &mut T as well, so borrows compose). Owning instead of &mut T-borrowing keeps the API honest across backends: buffer views genuinely need exclusive access while cairo targets are shared handles.

Construct with RenderContext::new, chain optional configuration methods, then call draw methods. Fonts are injected via icon_font and label_font; icon calls fall back to a placeholder and text calls to the bitmap renderer when no font is configured.

§Examples

use nerd_fonts_rs::fonts::label_font;
use nerd_fonts_rs::fonts::nerd_font;
use smearor_commons_buffer::PixelBuffer;
use smearor_commons_color::Color;
use smearor_commons_drawing::RenderContext;
use smearor_commons_geometry::Fraction;
use smearor_commons_geometry::Size;

let mut buf = PixelBuffer::new(Size::new(96, 96));
let mut ctx = RenderContext::new(&mut buf)
    .icon_font(nerd_font())
    .label_font(label_font())
    .background(Color::<f64>::new(0.12, 0.12, 0.12))
    .icon_color(Color::<f64>::new(0.4, 0.7, 1.0))
    .active(true);
ctx.fill_background().unwrap();
ctx.draw_icon('\u{F11B}').unwrap();
ctx.draw_label("gamepad").unwrap();

pub fn new(target: T) -> Self

Creates a new RenderContext over target with no colors configured, inactive state and no fonts configured. Colors left unset resolve to DrawTarget::default_text_color of the target.

pub fn fill_background(&mut self) -> Result<(), T::Error>

Fills the entire pixel buffer with the configured background color.

Does nothing if no background color was set.

Source

pub fn draw_icon(&mut self, codepoint: char) -> Result<(), T::Error>

Draws an icon by its Unicode codepoint, centered in the upper portion of the buffer.

Uses the configured icon_font and icon_color. Does nothing when no icon font is configured.

Source

pub fn draw_icon_by_name( &mut self, icon_name: &str, resolve_codepoint: impl Fn(&str) -> Option<char>, ) -> Result<(), T::Error>

Draws an icon by name using the configured icon_font, resolving the codepoint via the provided resolver function.

Uses the configured icon_color and is_active state. Falls back to a placeholder if no icon font is configured or the icon is unavailable.

Source

pub fn draw_label(&mut self, text: &str) -> Result<(), T::Error>

Draws a text label at the bottom of the buffer using the configured label_font (falling back to icon_font, then to the bitmap renderer).

Uses the configured text_color and is_active state.

Source

pub fn draw_text( &mut self, text: &str, baseline_y: Pixels<f32>, ) -> Result<(), T::Error>

Draws text centered horizontally at the given y-baseline.

Uses the configured text_color. The font size is derived from the buffer height unless overridden.

Source

pub fn draw_text_sized( &mut self, text: &str, baseline_y: Pixels<f32>, font_size: Pixels<f32>, ) -> Result<(), T::Error>

Draws text centered horizontally at the given y-baseline with a custom font size.

pub fn draw_text_at( &mut self, position: Vec2<Pixels, f32>, text: &str, font_size: Pixels<f32>, ) -> Result<(), T::Error>

Draws text with its baseline starting at position using the configured font and text_color.

pub fn draw_progress_bar( &mut self, value: Fraction, height: Pixels<f32>, ) -> Result<(), T::Error>

Draws a horizontal progress bar of the given height at the bottom of the buffer.

value is clamped to [0.0, 1.0]. Uses the configured icon_color.

Draws a grid of icons by name using the configured icon_font, resolving codepoints via the provided resolver function.

Uses the configured is_active state for default color selection. Does nothing when no icon font is configured.
