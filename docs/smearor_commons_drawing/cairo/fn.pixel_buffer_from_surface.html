pub fn pixel_buffer_from_surface(
    surface: &mut ImageSurface,
) -> Result<PixelBuffer<BgraPremultiplied>, DrawingError>
Expand description

Copies an ImageSurface’s pixels into a packed PixelBuffer<BgraPremultiplied>, honoring the surface’s stride (cairo may pad rows beyond width·4).

Fails when the surface is not ARgb32, when its pixel data is still borrowed by a live Context or surface clone (DrawingError::SurfaceBorrowed), or on a cairo status error. For GTK textures follow with .into_unpremultiplied().into_rgba().
