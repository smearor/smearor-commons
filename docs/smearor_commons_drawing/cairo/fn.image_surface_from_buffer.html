Expand description

Copies a [PixelBuffer]’s pixels into a fresh ARgb32 [ImageSurface] — the inverse of pixel_buffer_from_surface. Channels are converted through the [PixelFormat] interface: whatever the source format, each pixel is re-encoded as premultiplied BGRA (the ARgb32 memory layout).

This is the surface upload consumers need for cairo path helpers like tile_fill (e.g. a decoded texture tile).
