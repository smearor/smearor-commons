Module path 

Source
Expand description

Generic cairo path building blocks harvested from consumer code.

These helpers append segments to the current path of a [Context]; the caller decides whether to fill or stroke the result. They are cairo-only because they emit cairo path commands — the geometry they trace (polyline, spline, wave, band, rounded rectangle) is backend-neutral, but the raster backend has no consumer for it.

  • polyline_path: straight segments through the points (qdo36 px_polyline_path lineage — road and rail edges).
  • smooth_path: Catmull-Rom→cubic-Bézier spline through the points (qdo36 smooth_path — watercourse curves).
  • wavy_path: arc-length-sampled sine wave along the polyline (qdo36 wavy_path — boat wakes; phase lets shared edges agree).
  • band_path: closed polygon between two bank lines (qdo36 band_path — river bodies).
  • rounded_rect_path: the canonical four-arc rounded rectangle (osk-rs draw_rounded_rect lineage) — cairo has no built-in one.
  • tile_fill: repeat a tile surface over a rect (qdo36 tile_fill — ground textures panning with the map).

Functions§

band_path
The closed band between two bank lines: left_bank traced forward, right_bank reversed — the filled body between them (qdo36 band_path — river bodies).
polyline_path
Straight segments through points, starting a new sub-path.
rounded_rect_path
Rounds rect’s corners into the current path with four 90° arcs — the canonical rounded-rectangle path (osk-rs lineage). radius clamps to half the shorter side so degenerate rects stay valid.
smooth_path
A smooth spline through points (Catmull-Rom → cubic Bézier).
tile_fill
Fills (0, 0, width, height) with tile repeated, anchored so the tile origin sits at pin — the texture repeats infinitely and pans with the anchor point (qdo36 tile_fill — map ground textures).
wavy_path
A sine wave traced along points: the polyline is sampled at fine arc-length steps and each sample shifts perpendicular to the local segment direction. phase offsets the wave’s arc position, so polylines sharing a stretch trace the same wave (qdo36 wavy_path).
