Struct CairoTarget

pub struct CairoTarget { /* private fields */ }
Expand description

A cairo render target: owns a [cairo::Context] handle plus the pixel extent it draws to.

Cloning a Context is a refcount bump — CairoTarget is a value type, deliberately not a borrow wrapper. GTK callbacks hand out &Context; new clones that handle, so a target can be constructed inside snapshot/set_draw_func callbacks without ceremony, and RenderContext can own it like BufferViewMut.

The extent is declared, not read back: not every surface type reports one (recording surfaces are unbounded), and DrawTarget needs a reliable size().

Use context for backend-specific operations that are not part of the shared vocabulary — save/restore, transforms, patterns, surface sources.

pub fn status(&self) -> Result<(), Error>

The deferred cairo status of the wrapped context.

cairo reports errors lazily: once a surface or context fails, every subsequent operation is a no-op and status() keeps reporting the sticky error. Draw methods already propagate Self::Error; this is the optional end-of-pass check.

pub fn draw_halo_text( &mut self, text: &str, at: Vec2<Pixels>, angle: Radians, halo: Color<f64>, ink: Color<f64>, ) -> Result<(), Error>

Draws text centered at at, rotated by angle, tracing the glyph outlines in halo before filling them in ink — the wide round-joined stroke lifts the text off its background (qdo36 place_label lineage — district captions over map detail). Face and size come from the caller’s toy font configuration; the halo width derives from the configured font height like the original’s font_px·0.28 policy.
