Expand description

A render target that implements the full DrawOps vocabulary and reports its own pixel extent.

This is the bound crate::RenderContext places on the target it owns: its convenience methods need the target’s size for layout (icon placement, progress bar position). Both buffer-side types implement it — PixelBuffer and BufferViewMut — and backend targets like CairoTarget carry their surface size for it.

fn default_text_color(&self, is_active: bool) -> Color<u8>

The default color for text and icons in the given is_active state. This is the single anchor for the crate’s color policy: the Option<Color> parameters of the capability traits resolve None to this value. Backends may override it — a themed target could derive its defaults from the UI theme.

Source

fn status(&self) -> Result<(), Self::Error>

The target’s deferred error state, if the backend has one.

Draw methods already propagate Self::Error per call; this is the optional end-of-pass check for backends whose errors are sticky — a failed cairo surface keeps reporting the same error through status() while subsequent draws no-op. The raster target is infallible and always reports Ok.
