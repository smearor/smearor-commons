Expand description

Fraction-based indicator drawing operations: progress bars and circular gauges. Values are clamped to [0.0, 1.0].

Required Methods§

Source

fn draw_gauge(&mut self, gauge: Gauge) -> Result<(), Self::Error>

Draw gauge: a faint track ring plus a color arc starting at 12 o’clock and sweeping value of a full turn clockwise (sysinfo draw_gauge lineage, generalized to Fraction semantics).

Multi-arc gauges (network up/down) and threshold markers (temperature) stay consumer-side policy built on this primitive.
