Expand description

Primitive surface operations: background fills plus the highlight primitives harvested from consumer code — rect fills, ring strokes and dots over Rect/Circle geometry.

The methods only write the declared pixel area; row padding and memory beyond the view extent stay untouched. alpha composes with the color’s own alpha channel; the rendered result is source-over blended onto existing pixels, matching what a cairo backend produces with set_source_rgba + fill.

fn fill_background( &mut self, color: impl Into<Color<u8>>, ) -> Result<(), Self::Error>

Fill the entire view with a solid background color.

Packed views reinterpret the &mut [u8] data as &mut [u32] (RGBA = 4 bytes = one u32 in little-endian) and use slice::fill() for SIMD-vectorized writes. Strided views fill each row’s pixel bytes and leave row padding untouched.

Stroke centered on the rect edge like cairo: the stroke region is rect ± line_width/2 minus the interior — implemented as the expanded outline minus the shrunken one.

fn stroke_arc(&mut self, spec: StrokeArc) -> Result<(), Self::Error>

The rim band |dist − r| ≤ w/2 masked by arc’s interval - caps are the same geometry as stroke_polyline’s: round ends scan endpoint circles, square ends scan a tangent extension.
