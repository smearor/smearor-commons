Expand description

Text drawing operations: bottom labels and centered text.

The font is injected per call as Option<&FontVec>; a None font falls back to the built-in bitmap renderer.

fn draw_text( &mut self, font: Option<&FontVec>, position: Vec2<Pixels, f32>, text: &str, font_size: Pixels<f32>, color: impl Into<Color<u8>>, ) -> Result<(), Self::Error>

Draw a text run with its baseline starting at position, using the injected font. A None font falls back to cairo’s toy text API on the cairo backend (system Sans) and to the built-in bitmap renderer on the raster backend (which keeps its own layout, ignoring position).
