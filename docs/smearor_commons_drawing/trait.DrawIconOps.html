Expand description

Icon drawing operations: named icons resolved through a caller-provided codepoint resolver, raw codepoints, a placeholder and icon grids.

The icon font is injected per call — DrawIconOps::draw_icon takes Option<&FontVec> and falls back to DrawIconOps::draw_icon_placeholder on None; the other methods take &FontVec and are simply not called when no font is available.

fn draw_icon(&mut self, icon: Icon<'_>) -> Result<(), Self::Error>

Draw an icon centered on the image, occupying the upper portion.

The icon name is resolved to a codepoint via the caller-provided resolver function. If no font is injected or the icon is unknown, a circular placeholder is drawn instead.
