Struct BufferView 

Source 
pub struct BufferView<'a, F = Rgba> { /* private fields */ }
Expand description

A read-only view of borrowed pixel memory with row stride.

Generalizes the (pixels, width, height) triple for foreign memory where rows may carry padding: stride counts bytes per row and is at least the packed row width. Wayland SHM buffers and framework surfaces are the motivating cases.

pub fn sample_nearest(&self, uv: Vec2<()>) -> Color<f64>

Nearest-texel sampling - the texel whose center is closest to uv (pixelate-style, no interpolation). Empty views yield transparent black.

Source

pub fn sample_bilinear(&self, uv: Vec2<()>) -> Color<f64>

Bilinear sampling - the weighted mean of the four surrounding texels, clamp-to-edge on every tap. Empty views and non-finite uv coordinates (warped effect coords can go inf/NaN) yield transparent black.

Source

pub fn cone_offsets( radius: Vec2<()>, directions: u32, taps: u32, ) -> Vec<Vec2<()>>

The ray offsets of a radial (cone) blur: taps samples along each of directions evenly spaced rays of radius uv units around the sample point. The radius is a Vec2, so anisotropic (elliptical) blurs like radius_px / size are expressible. Compute once per frame - the same offsets serve every pixel’s sample_cone call.

Source

pub fn sample_cone(&self, uv: Vec2<()>, offsets: &[Vec2<()>]) -> Color<f64>

Cone-blur sampling - the mean of bilinear taps at uv plus each precomputed offsets entry (see cone_offsets). An empty offset list degenerates to the plain sample_bilinear tap.

Source

pub fn sample_radial_blur( &self, uv: Vec2<()>, radius: Vec2<()>, directions: u32, taps: u32, ) -> Color<f64>

Radial-blur sampling - the mean of taps bilinear samples along directions evenly spaced rays of radius uv units around uv. A zero component degenerates to the center texel. For per-pixel use prefer cone_offsets

  • sample_cone: this convenience recomputes the ray table on every call.
