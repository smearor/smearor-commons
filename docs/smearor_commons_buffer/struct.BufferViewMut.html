Struct BufferViewMut 

Source 
pub struct BufferViewMut<'a, F = Rgba> { /* private fields */ }
Expand description

A mutable view of borrowed pixel memory with row stride - the rendering target for draw operations on foreign buffers.

See crate::BufferView for the stride semantics; this is the &mut counterpart draw code writes into.

Source

pub fn fill(&mut self, pixel: &[u8])

Fills every pixel with pixel (F::BYTES_PER_PIXEL bytes).

Packed views write the pattern over the whole slice in one pass; strided views repeat it per row, leaving padding untouched. Does nothing when pixel is not exactly one pixel wide.
