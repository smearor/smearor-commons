Pixel and graphics buffer types - ownership, format, extent and stride.

PixelBuffer owns a packed pixel buffer, BufferView and BufferViewMut borrow strided foreign memory (Wayland SHM, framework surfaces), and BufferMetadata carries the format-agnostic width/height/stride triple. The pixel format is a type-level marker (Rgba, Bgra) implementing PixelFormat, so format mismatches are compile errors rather than runtime checks.

Drawing operations live downstream (pixel-drawing); framework bridges (image, cairo, gtk4, smithay) are added behind dependency-named features.
