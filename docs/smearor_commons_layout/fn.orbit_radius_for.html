pub fn orbit_radius_for<U>(
    bounds: Rect<U>,
    gap: impl Into<Distance<U>>,
) -> Distance<U>
Expand description

The orbit radius clearing bounds: half the host diagonal plus gap, so items on a full-circle orbit never touch the host’s bounding circle. Consumers with non-circular hosts may pick a larger radius or accept nearer passes along the short axes.
