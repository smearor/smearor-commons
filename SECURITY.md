# Security Policy

## Supported Versions

The project is in early development (`0.x`). Security fixes land on the
`main` branch only; there are no maintained release branches yet.

## Reporting a Vulnerability

Please report security issues privately:

- Email: hanack@nooblounge.net
- Or open a private security advisory on GitHub
  (Security → Advisories → "Report a vulnerability")

Please do **not** file public issues for vulnerabilities. We aim to
acknowledge reports within a few days and to coordinate a fix and
disclosure timeline with you.
