Expand description

Layer-shell surface configuration shared by Smearor apps.

The layer/namespace/monitor/exclusive_zone quartet the ecosystem repeats across CLI arguments, configuration files and runtime state. Consumers needing extra fields wrap it with #[serde(flatten)] on a LayerConfig member.

Fields§

§layer: Option<SmearorLayer>

The layer-shell layer; None leaves the surface on the compositor’s default layer.

§namespace: Option<String>

Layer-shell namespace - compositors match window rules on it.

§monitor: Option<u32>

Monitor index the surface appears on; None uses the primary monitor.

§exclusive_zone: Option<Pixels<i32>>

Exclusive zone: None enables the auto-exclusive-zone, [Pixels::new(0)] disables it (overlay mode), other values reserve that many pixels for the surface.

i32-backed because [gtk4_layer_shell] consumes i32; serde keeps the bare-number wire format.

Source

pub fn merge(self, overrides: &Self) -> Self

Returns self with every field present in overrides replacing the local value - the CLI-over-config merge used by Smearor apps.

Option fields cannot distinguish “unset” from “explicitly unset”: an overrides field that is None never clears a configured value.
