Struct Vec2

pub struct Vec2<U = (), T = f64> {
    pub x: T,
    pub y: T,
    /* private fields */
}
Expand description

A 2D point or vector tagged with its coordinate unit U and numeric component type T.

The phantom unit distinguishes positions in millimeters (Vec2<Millimeters>), raw device units and screen pixels (Vec2<Pixels>) so they cannot be mixed up; T defaults to f64 for domain math but can be any component type the boundaries need (Vec2<(), i32> for smithay Point<i32, K> and textures, Vec2<(), f32> for graphene). The unit-erased form Vec2<(), T> is the boundary representation - it deliberately carries no coordinate-space claim and converts into any framework space; crate::Position and crate::Size are readable aliases for it. Serializes as a flat {"x": .., "y": ..} map; the unit marker is skipped. With the async-graphql feature, Vec2<Millimeters> is exposed as the GraphQL object type Point.

pub fn rotated_bounds(&self, rotation: RotationRad) -> Self

The bounding-box size of an axis-aligned rectangle of this size rotated by rotation around its center - the forward map bb(v) = A·v with A = [[cos, sin], [sin, cos]] over the absolute sine/cosine.

pub fn unrotated_bounds(&self, rotation: RotationRad) -> Self

Inverse of Self::rotated_bounds: the axis-aligned size that, rotated by rotation, yields this bounding box - the map A⁻¹·v with det(A) = cos(2θ).

The determinant vanishes at 45° + k·90° where no finite solution exists for non-square boxes; components then hold ±inf/NaN and callers must apply their own fallback.

Source

pub fn unrotated_fit(&self, aspect: AspectRatio, rotation: RotationRad) -> Self

The largest rectangle of aspect ratio aspect (width/height) whose rotation-rotated bounding box fits inside a rectangle of size self - the inscribed, aspect-preserving counterpart of Vec2::unrotated_bounds.

Solves A·(aspect·h, h) <= self for the largest h over the absolute sin/cos matrix A: the tighter of the two axis constraints wins. Unlike the exact inverse solve this never diverges and never goes negative - rotating a rectangle by any angle keeps such an inscribed solution bounded. At aspect == 1 it degenerates to the square fit min(w, h) / (|cos| + |sin|).

aspect is strictly positive by construction (AspectRatio); negative components of self are clamped to Vec2::ZERO.

Source

pub fn unrotated_cover( &self, aspect: AspectRatio, rotation: RotationRad, ) -> Self

The smallest rectangle of aspect ratio aspect (width/height) whose rotation-rotated bounding box contains a rectangle of size self - the covering, aspect-preserving counterpart of Vec2::unrotated_bounds, dual to Vec2::unrotated_fit.

Solves A·(aspect·h, h) >= self for the smallest h over the absolute sin/cos matrix A: the looser of the two axis constraints wins, so the result covers self on both axes and is tight on at least one of them. Like unrotated_fit this never diverges and never goes negative. At aspect == 1 it degenerates to the square cover max(w, h) / (|cos| + |sin|).

Covering with the aspect of a feasible Vec2::unrotated_bounds solve reproduces that solve exactly - both axes then constrain the same height. That makes the aspect-clamped cover a continuous fallback for the exact solve: the cover meets it at the clamp edge and relaxes into overhang beyond it.

aspect is strictly positive by construction (AspectRatio); negative components of self are clamped to Vec2::ZERO.
