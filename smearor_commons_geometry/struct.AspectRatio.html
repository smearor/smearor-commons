Struct AspectRatio 

Source 
pub struct AspectRatio(/* private fields */);
Expand description

An aspect ratio - width / height of a crate::Size-like extent (1.0 = square).

Wraps the plain f64 so ratios cannot be confused with other dimensionless scalars such as crate::ScaleFactor. The value is strictly positive and finite by construction: AspectRatio::new rejects non-positive and non-finite inputs, so consumers like crate::Vec2::unrotated_fit need no defensive aspect <= 0 guard - “invalid” is unrepresentable.
