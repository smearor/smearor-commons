Expand description

Convenience geometry accessors for gtk4::Widgets.

Import this trait to call WidgetSizeExt::allocated_size on any widget. Named after gtk_widget_get_allocated_* rather than size, which collides with gtk4::prelude::WidgetExt::size.

Required Methods§

Source

fn allocated_size(&self) -> Size<i32>

The widget’s allocated pixel extent.

Source

fn measure_size(&self) -> (Size<i32>, Size<i32>)

The widget’s measured minimum and natural pixel extents as (minimum, natural), measured unconstrained (for_size = -1) in both orientations.

Source

fn measure_axis(&self, orientation: Orientation, for_size: i32) -> Vec2<(), i32>

The widget’s measured minimum and natural extent on one axis (x = minimum, y = natural) for a concrete for_size constraint - e.g. the height a widget reports given a fixed width, which measure_size cannot express.

The center of the widget’s allocated area in pixel coordinates - the natural origin for pointer hit tests and radial layouts.
