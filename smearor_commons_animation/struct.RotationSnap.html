Struct RotationSnap 

Source 
pub struct RotationSnap { /* private fields */ }
Expand description

Tracks a rotate gesture and decides when it snaps to the next QuarterTurn.

Lifecycle per gesture: construct with the rotation captured at gesture begin, feed every reported cumulative gesture angle into update, then consume the session with end - end yields the rotation to restore when the drag never reached the snap threshold.

Three stages per drag: below direction nothing happens; crossing it locks the drag direction and emits a one-shot feedback nudge signalling engagement; crossing snap emits the target quarter turn once and freezes the session.

Source

pub fn with_thresholds( initial: RotationRad, snap: Degrees, direction: Degrees, feedback: Degrees, ) -> Self

A session with explicit thresholds: snap is the accumulated drag that settles the snap, direction locks the direction and emits feedback, feedback is the nudge amount applied in the drag direction.

snap should exceed direction so the direction is known when the snap fires; a feedback of Degrees::ZERO still reports a (zero) nudge.

Source

pub fn update(&mut self, angle: RotationRad) -> SnapUpdate

Feeds the cumulative gesture angle - reported relative to gesture begin - into the session.

The delta to the previous report is unwrapped across the 0°/360° boundary before accumulating: raw reports jump ±360° there while the drag itself is continuous.

Source

pub fn end(self) -> Option<RotationRad>

Finishes the session: the rotation to restore when the drag never reached the snap threshold, None when a snap target was emitted.

Restoring initial undoes the engagement-feedback nudge the consumer may have applied mid-drag.
