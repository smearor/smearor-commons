Struct Color 

Source 
pub struct Color<T> {
    pub r: T,
    pub g: T,
    pub b: T,
    pub a: T,
}
Expand description

Generic RGBA color with four components of type T.

Use Color<f64> or Color<f32> for normalized channel values in [0.0, 1.0] (CSS/GTK/cairo operations) and Color<u8> for pixel-native channel values in [0, 255] (software rendering).

Conversions between the instantiations are provided via From/Into. Parsing and formatting use FromStr/Display. Parsing accepts all common hex forms (#RGB, #RGBA, #RRGGBB and #RRGGBBAA - the leading # is mandatory, see HexColor) and the CSS Color Level 4 named colors ("red", "rebeccapurple", "transparent", ASCII case-insensitive, see CssNamedColor).

Semantic color types (FigureColor, LineColor, PawnColor, …) stay in consumer crates as thin newtype wrappers around Color<T>.
