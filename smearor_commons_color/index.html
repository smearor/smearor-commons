Crate smearor_commons_color 

Source
Expand description

Generic color types for the Smearor ecosystem.

Channel-generic Color<T> (normalized f64/f32 and byte u8), parsing via FromStr/Display and consolidated color operations. Textual representations have dedicated types: HexColor validates #-prefixed hex strings; CssNamedColor, PantoneNamedColor and PantoneFhiNamedColor enumerate the CSS Color Level 4, Pantone Matching System and Pantone FHI color vocabularies. Palette<N, T> maps semantic color names to colors: keys are either a PaletteDefinition enum (type-safe vocabulary, generated by palette_definition!) or the dynamic NamedColor. gtk4/cairo conversions live behind feature gates.

Semantic color types (FigureColor, LineColor, PawnColor, …) stay in consumer crates as thin newtype wrappers around Color<T>.

static_palette
Builds a StaticPalette from name => color pairs - the generated expression is const-evaluable and usable in const and static contexts. All values must be const expressions (Color::<u8>::new(0xED, 0xD4, 0x9E) or Color::<u8>::from_rgb_u32(0xEDD49E)) and names must already have the key type (BoardSlot::Light, NamedColor::new("light")) - no Into conversion happens in const contexts.
