Expand description

The byte layout of a pixel format - implemented by marker types.

Implementors are zero-sized tags carried as PhantomData on crate::PixelBuffer and the buffer views; the associated constants supply the byte arithmetic and a runtime identifier.

Required Associated Constants§

Source

const BYTES_PER_PIXEL: usize

Bytes per pixel.

Source

const HAS_ALPHA: bool

Whether the format carries an alpha channel - false for formats without alpha and for padding-channel formats like crate::Rgbx, where the fourth byte is ignored.

Source

const ID: PixelFormatId

The runtime identifier for diagnostics and wire formats.
