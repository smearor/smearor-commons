Re-exports all drawing capability traits — use smearor_commons_drawing::prelude::*; brings the full vocabulary into scope for method calls.

Structs§

Codepoint
A codepoint draw specification: which glyph, through which font, at which position and size, in which color.
FillCircle
A circle fill’s draw specification: geometry, color and alpha.
FillRect
A rect fill’s draw specification: geometry, color and alpha.
Gauge
A circular gauge’s draw specification: ring geometry, fill fraction, arc color and track color.
Icon
An icon draw specification: which icon, resolved through which font and codepoint resolver, in which state and color.
IconGrid
An icon grid’s draw specification: which icons, through which font and codepoint resolver, in which grid and state.
ProgressBar
A progress bar’s draw specification: fill fraction, color and strip height. The backends anchor the strip at the target’s bottom edge, raised by PROGRESS_BAR_BOTTOM_MARGIN.
StrokeRect
A rect outline’s draw specification: geometry, color, stroke width and alpha. The stroke is centered on the rect edge with the given line_width — the consumer computes any inset policy itself.

Constants§

PROGRESS_BAR_BOTTOM_MARGIN
Bottom-edge clearance under the progress bar — part of the shared visual contract so both backends render the strip at the same position.

Traits§

DrawBackend
Base trait that ties a target’s capability impls to a single error type, shared across all capability traits via the supertrait bound.
DrawIconOps
Icon drawing operations: named icons resolved through a caller-provided codepoint resolver, raw codepoints, a placeholder and icon grids.
DrawOps
Umbrella trait bundling all drawing capability traits.
DrawPrimitiveOps
Primitive surface operations: background fills plus the highlight primitives harvested from consumer code — rect fills, ring strokes and dots over Rect/Circle geometry.
DrawProgressOps
Fraction-based indicator drawing operations: progress bars and circular gauges. Values are clamped to [0.0, 1.0].
DrawTarget
A render target that implements the full DrawOps vocabulary and reports its own pixel extent.
DrawTextOps
Text drawing operations: bottom labels and centered text.
